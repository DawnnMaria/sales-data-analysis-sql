# 📊 Sales Data Analysis Project (MySQL)

## 📌 Overview
This project analyzes customer sales data using SQL to generate business insights such as top customers, revenue trends, and product performance.

---

## 🧠 Objectives
- Analyze revenue by product and category  
- Identify high-value and repeat customers  
- Evaluate monthly sales trends  
- Transform raw data into actionable insights  

---

## 🗄️ Database Structure
The project uses three relational tables:

- **customers** – customer information  
- **products** – product details and pricing  
- **orders** – transaction records  

Relationships are established using primary and foreign keys.

---

## 🔍 Key SQL Techniques Used
- INNER JOIN  
- GROUP BY  
- SUM(), COUNT()  
- HAVING  
- ORDER BY  
- DATE_FORMAT()  

---

## 📈 Key Insights
- Certain products generate significantly higher revenue than others  
- A small group of customers contribute the most revenue  
- Revenue fluctuates monthly, showing trends over time  
- Repeat customers indicate potential for retention strategies  

---

## 🛠️ Tools Used
- MySQL  
- MySQL Workbench  
- GitHub  

---

## ▶️ How to Run This Project
1. Open MySQL Workbench  
2. Run `sales_analysis.sql`  
3. Execute queries to view insights  

---

## 🎯 Business Impact
This project demonstrates how SQL can be used to transform raw transactional data into insights that support decision-making in sales, marketing, and customer retention.
